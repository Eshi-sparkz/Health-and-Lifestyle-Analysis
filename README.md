# 💪 Health and Lifestyle Data Analysis

This project analyzes **health and lifestyle data** using **Microsoft Power BI** to uncover insights into how daily habits and behaviors influence overall well-being. The report offers a data-driven understanding of patterns in diet, exercise, sleep, and other lifestyle indicators.


## 📋 Project Overview

This analysis aims to identify key lifestyle factors that impact personal health outcomes.
Using **interactive visualizations**, the dashboard presents trends and relationships between:

* 🥗 **Diet and Nutrition**
* 🏃‍♀️ **Physical Activity Levels**
* 😴 **Sleep Duration and Quality**
* ❤️ **Health Metrics (BMI, heart rate, etc.)**
* 🧠 **General Well-being and Habits**


## 📊 Power BI Dashboard

The Power BI report (`Esi Abaka-Quansah (Health and Lifestyle).pbix`) provides:

* **Dynamic charts and KPIs** for easy exploration
* **Comparisons across demographic groups** (age, gender, activity type, etc.)
* **Correlation visuals** showing the impact of lifestyle choices on health outcomes
* **Trend analysis** over time for fitness and wellness progress


## ⚙️ Tools Used

| Tool                     | Purpose                             |
| ------------------------ | ----------------------------------- |
| **Power BI**             | Visualization and data storytelling |
| **Excel / CSV (Source)** | Data cleaning and preparation       |
| **DAX Measures**         | Custom calculations for KPIs        |


## 💡 Insights Discovered

* Individuals with **balanced sleep and regular exercise** show better overall health scores.
* **High-calorie diets** tend to correlate with higher BMI and lower fitness ratings.
* **Active lifestyles** lead to better heart rate stability and general wellness.
* Sleep patterns play a major role in **daily performance and recovery**.
